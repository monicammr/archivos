# Archivos necesarios para ejecutar el contenido

Este repositorio solo incluye material en formato PDF y no contiene código ejecutable ni dependencias externas. Para consultar el contenido basta con abrir cualquiera de los siguientes archivos con un lector de PDF:

- `demostracion_de_valor_de_correlacion.pdf`
- `docs/demostracion_de_valor_de_correlacion.pdf`

No se requieren archivos adicionales ni pasos de instalación.
