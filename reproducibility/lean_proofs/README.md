# Formal proofs (Lean 4 + Mathlib)

This folder contains **all** formal proofs that accompany the manuscript
*"Few biological parameters suffice to reproduce measured dynamics in systems biology models:
local sensitivity-based reduction with formally verified mathematical guarantees"*.
It is a self-contained Lake project: everything can be compiled from here with one command.

* **31 theory modules, 289 theorems and lemmas** (one `.lean` file per module, listed below).
* **28 benchmark models** translated from SBML (`Models/`), each with a final theorem stating
  smoothness of the vector field, existence of the solution on the simulated horizon and
  non-negativity of concentrations.
* No `sorry` and no `axiom` declarations. `#print axioms` reports only Lean's standard axioms
  (`propext`, `Classical.choice`, `Quot.sound`).
* Toolchain: Lean `v4.23.0` (file `lean-toolchain`), Mathlib `v4.23.0` (file `lakefile.lean`).

The complete list of theorems, with a one-line description of each, is in
[`THEOREMS.md`](THEOREMS.md) (generated by `catalogo.py`). The statement of every theorem in mathematical notation, with the meaning of each symbol, is in [`FORMULAS.md`](FORMULAS.md) (also the Supplementary Note "Statements of the formal theorems" of the paper; the Supplementary Note "Logical sequence of the formal proofs" explains the logical order of the modules).

## How to compile

1. Install [elan](https://github.com/leanprover/elan) (the Lean version manager).
2. From this folder run

   ```bash
   ./verify.sh
   ```

   which (i) checks that no file contains `sorry` or `axiom`, (ii) downloads the precompiled
   Mathlib (`lake exe cache get`), (iii) compiles the theory and the models (`lake build`) and
   (iv) prints the axioms used by every theorem (`CheckAxioms.lean`) and by the final theorem of every model (`CheckModelAxioms.lean`).

   Equivalent manual steps: `lake exe cache get && lake build && lake env lean CheckAxioms.lean`.

The theory compiles in a few minutes. The models take longer; the two largest
(Froehlich, 1,228 species, and Chen, 500 species plus time) are split into parts of at most 3 GB of memory
each and take about 30 min each on a laptop. The log of our complete build is in
[`BUILD_LOG.md`](BUILD_LOG.md).

**Fidelity of the model files.** The Lean files in `Models/` were generated from the SBML models of the
benchmark by `../lean_translation/sbml_to_lean.py` (running it again regenerates identical files).
`../lean_translation/verify_translation.py` reads the rate laws, stoichiometry, parameter values and
initial values directly from these files and compares them with the SBML models evaluated by libRoadRunner;
for all 28 models the agreement is at the level of rounding error
(`../results/sbml_to_lean/translation_fidelity.json`), and `../lean_translation/mutation_control.py`
shows that a 1 % change of one number of a file is detected.

**Language.** The reference for every statement is in English: [`FORMULAS.md`](FORMULAS.md) gives the
statement of every theorem and lemma in mathematical notation, with the meaning of each symbol (also the
Supplementary Note "Statements of the formal theorems"). The doc comments inside the `.lean` files, the
header comments of the generated model files and the catalogue [`THEOREMS.md`](THEOREMS.md) extracted
from them by `catalogo.py` are partly in Spanish; they do not affect the proofs and were left unchanged
so that the files are exactly those that were compiled.

## What is and is not proved

The development proves the mathematical statements on which each step of the method relies
and the regularity of the translated models. It does **not** prove that a selected subset remains
adequate far from the nominal parameters (this is assessed numerically in the manuscript), nor
the correctness of the numerical ODE simulator.
