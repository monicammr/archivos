\section*{Supplementary Table S3. Formal proofs}

All formal proofs are collected in the folder \texttt{lean\_proofs/} of the repository, a self-contained Lean~4 project (Lean 4.23.0, Mathlib v4.23.0) that compiles with a single command (\texttt{./verify.sh}). It contains 31 theory modules with 289 theorems and lemmas, and 22 benchmark models translated from SBML. No file contains \texttt{sorry} or \texttt{axiom}, and \texttt{\#print axioms} reports only \texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound} for every theorem. The file \texttt{THEOREMS.md} in that folder lists every theorem and lemma; $n$ is the number of theorems and lemmas per module.

\textbf{Verified benchmark models.} Armistead, Bachmann, Blasi, Boehm, Borghans, Brannmark, Chen (500 species, in four parts), Crauste (horizon $T\le 1$), Elowitz, Fiedler, Froehlich (1,228 species, in twelve parts), Giordano, Lang, Okuonghae, Rahman, Raia, Raimundez, SalazarCavazos, Sneyd, Weber, Zhao and Zheng (folder \texttt{lean\_proofs/Models/}). For each model, the final theorem establishes that the vector field is smooth on its domain, that the solution exists on the simulated horizon and that concentrations remain non-negative.

\section*{Supplementary Note. Verification of the simulator}

Our simulation of the measured outputs was compared, at the nominal parameters, with the reference simulations distributed with the benchmark, matching each measurement by observable, condition and time. For the problems with comparable reference files the median relative difference was below $10^{-5}$ in all but five cases: Chen ($1.1\times 10^{-4}$), Zheng (whose reference file contains the measured data rather than a simulation), Crauste (0.8\%, very stiff model), Lang (2.8\%, an oscillating cell-cycle model simulated to $t=136{,}472$, where peaks differ by an accumulated phase shift) and Perelson (17\%; the initial state of the model is stationary and our simulation respects it, which suggests that the reference was generated with different values). Several problems have no comparable reference (no file, or different condition identifiers). The full comparison is given in the repository (\texttt{certificados/resultados/salidas/VERIFICACION\_SIMULADOR.md}).
