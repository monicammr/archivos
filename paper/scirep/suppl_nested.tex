\snote{nested}

\subsection*{Motivation}

In the external validation experiment the reduced model fixes the non-selected parameters at $\theta_0$, the nominal point estimated from \emph{all} experimental data (including the test set). A reviewer might argue that, because the fixed parameters are anchored at a value that has ``seen'' the test data, the reduced model enjoys an indirect informational advantage over the full model baseline (which is re-estimated using only training data). This supplementary note addresses that concern empirically.

\subsection*{Design}

For each admissible problem (excluding the five computationally slow systems: Bachmann, Chen, Isensee, Lang, and Raimundez) we ran a \emph{nested} (leakage-free) external validation:
\begin{enumerate}
  \item Fit the full model on \textbf{training data only} to obtain $\hat\theta_{\mathrm{train}}$ (the same quantity already computed as the full-model baseline in the main external validation).
  \item Fit the reduced model starting from $\hat\theta_{\mathrm{train}}$, with non-selected parameters fixed at $\hat\theta_{\mathrm{train}}$ rather than $\theta_0$; re-estimate $S\cup\Theta_C$ on training only.
  \item Evaluate $\chi^2/n$ on the held-out test set for the resulting nested reduced model.
\end{enumerate}
In this protocol the test set is never seen at any stage of constructing the reduced model.

\subsection*{Results}

Table~\ref{tab:nested} reports the results for the 24 problems evaluated (three additional admissible problems were excluded: Bertozzi, whose selected parameters act only in the test conditions; Blasi, with a single time point and no valid split; and Lucarelli, whose full model has 72 free parameters, making training re-estimation computationally infeasible; the five slow systems were excluded at the outset). The key finding is that the nested (leakage-free) $\chi^2/n$ ($\chi^2_{\mathrm{nested}}$) is virtually identical to the full-model training baseline ($\chi^2_{\mathrm{full,train}}$) in 23 of 24 problems (96\%), with differences below 0.1\% in every case but Raia, where the nested reduced model is \emph{better} than the full baseline (5.7\% lower $\chi^2$). This demonstrates that the informational advantage conferred by the $\theta_0$ anchor in the main experiment is negligible, and that the selected subset $S$ captures the full predictive capacity of the model even when the test set has never been seen during parameter selection or estimation.
