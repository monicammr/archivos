\snote{nested}

\subsection*{Motivation}

In the external validation experiment the reduced model fixes the non-selected parameters at $\theta_0$, the nominal point estimated from \emph{all} experimental data (including the test set). A reviewer might argue that, because the fixed parameters are anchored at a value that has ``seen'' the test data, the reduced model enjoys an indirect informational advantage over the full model baseline (which is re-estimated using only training data). This supplementary note addresses that concern empirically.

\subsection*{Design}

For each admissible problem we ran a \emph{nested} (leakage-free) external validation:
\begin{enumerate}
  \item Fit the full model on \textbf{training data only} to obtain $\hat\theta_{\mathrm{train}}$ (the same quantity already computed as the full-model baseline in the main external validation).
  \item Fit the reduced model starting from $\hat\theta_{\mathrm{train}}$, with non-selected parameters fixed at $\hat\theta_{\mathrm{train}}$ rather than $\theta_0$; re-estimate $S\cup\Theta_C$ on training only.
  \item Evaluate $\chi^2/n$ on the held-out test set for the resulting nested reduced model.
\end{enumerate}
In this protocol the test set is never seen at any stage of constructing the reduced model. Importantly, the search bounds for the free parameters in step~2 are also derived from $\hat\theta_{\mathrm{train}}$, not from $\theta_0$, ensuring the optimisation cannot exploit any test-set information encoded in the nominal values.

\subsection*{Results}

Table~\ref{tab:nested} reports the results for the 28 problems evaluated. Three admissible problems were excluded: Bertozzi (selected parameters active only in test conditions), Blasi (single time point, no valid split), and Lang (277 free parameters; full-model re-estimation would require days to weeks of computation). Chen was excluded because its full-model re-estimation did not complete within the available computation time. The key finding is that the nested (leakage-free) $\chi^2/n$ ($\chi^2_{\mathrm{nested}}$) is virtually identical to the full-model training baseline ($\chi^2_{\mathrm{full,train}}$) in 25 of 28 problems (89\%), with differences below 0.1\% in 19 of those 28. In two problems the nested reduced model slightly outperforms the full training baseline (Raia: $-5.1\%$; Smith: $-0.3\%$). The largest discrepancy occurs in Schwen et al.\ (2014; $+249\%$), where the optimisation starting from $\hat\theta_{\mathrm{train}}$ reached a worse local minimum for the two selected structural parameters; this reflects optimisation sensitivity to the starting point rather than a systematic leakage effect. Excluding Schwen, all remaining 27 problems show $\chi^2_{\mathrm{nested}}$ within 2.5\% of $\chi^2_{\mathrm{full,train}}$, confirming that the informational advantage conferred by the $\theta_0$ anchor in the main experiment is negligible.
